# Section 5: Web Design Rules and Framework

## Design Rules

- **Consistency**: same fonts, colors, spacing everywhere
- **Hierarchy**: bigger/bolder = more important
- **Whitespace**: don't cram things, let it breathe
- **Contrast**: text must be easy to read on its background
- **Alignment**: keep elements lined up in a grid
- **Color**: stick to 2-3 main colors
- **Typography**: max 2 fonts, readable size (16px+ for body)
- **Responsive**: should work on mobile, tablet, desktop
- **Accessibility**: alt text, good contrast, keyboard friendly
- **Simple navigation**: user finds things in 3 clicks or less

## Layout Basics

- **Box model**: content, padding, border, margin
- **Flexbox**: 1D layout (row or column)
- **Grid**: 2D layout (rows and columns)
- **Media queries**: change styles by screen size

## Frameworks

| Framework    | Use                                     |
| ------------ | --------------------------------------- |
| Bootstrap    | Ready-made components + 12-column grid  |
| Tailwind CSS | Utility classes, build directly in HTML |
| Bulma        | Clean, CSS-only, flexbox based          |

## Why Use a Framework

- Saves time
- Responsive out of the box
- Consistent look
- Less custom CSS

## Quick Tips

- Mobile-first approach
- Don't overuse animations
- Test on different screen sizes
- Reuse components
